# Sub2API 배포 및 운영 준법 서약

버전: v2026.06.10

이 문서는 Sub2API 인스턴스를 배포, 구성, 관리, 운영하거나 실질적으로 통제하는 개인, 조직 또는 권한을 부여받은 대표자에게 적용됩니다. 콘솔 기능에 계속 접근하거나 이를 사용하기 전에 확인 당사자는 이 문서 전체를 읽고 이해하며 수락해야 합니다.

## 1. 적용 범위

Sub2API는 오픈 소스 소프트웨어입니다. Sub2API를 기반으로 하는 자체 호스팅 배포, 수정, 호스팅 운영, 외부 서비스, 상업적 이용, 사용자 관리, 콘텐츠 처리, 데이터 처리, 결제 정산, 고객 지원 또는 상위 서비스 계정/API 이용에 대한 책임은 해당 인스턴스를 배포, 운영 또는 통제하는 당사자에게 전적으로 있습니다.

이 문서는 오픈 소스 라이선스, 상위 서비스 이용약관, 사용자 계약, 개인정보 처리방침, 데이터 처리 계약, 상업 계약, 규제 기관 신고, 행정 허가, 보안 평가 또는 적용 법률이나 계약에서 요구하는 기타 문서, 절차 또는 의무를 대체하지 않습니다.

## 2. 배포자 또는 운영자의 책임

확인 당사자는 자신의 소재지, 서버 소재지, 대상 사용자 소재지, 실제 사업 운영 장소 및 상위 서비스 제공자의 소재지에 적용될 수 있는 법률, 규정, 규제 요건, 업계 규칙, 계약상 의무 및 플랫폼 정책을 독립적으로 평가하고 지속적으로 준수해야 합니다.

확인 당사자는 해당 인스턴스의 배포와 운영에 필요한 모든 권한, 자격, 신고, 허가, 평가, 계약, 위험 통제 역량, 콘텐츠 안전 역량, 데이터 보호 역량, 민원 처리 체계 및 비상 대응 역량을 갖추고 있음을 보장해야 합니다. 오픈 소스 소프트웨어를 사용한다고 해서 이러한 의무가 이전되거나 면제 또는 경감되지 않습니다.

## 3. 관계 부존재 및 책임 분담

제3자 인스턴스, 상업 서비스, 유료 요금제, 사용자 유치, 콘텐츠 처리, 데이터 처리, 계정 이용, API 호출, 결제 정산, 고객 지원 또는 홍보 활동은 해당 배포자, 운영자 또는 통제자가 독립적으로 수행합니다. 이 프로젝트의 오픈 소스 성격, 코드 기여, 이슈 논의, 문서 유지보수, 버전 출시, 버그 수정, 커뮤니티 소통 또는 일반적인 기술 설명은 오픈 소스 프로젝트, 저작권자, 기여자 또는 유지관리자와 그러한 활동 사이에 참여, 권한 부여, 승인, 보증, 공동 운영, 대리, 파트너십, 고용, 운영 권한 부여, 공동 통제, 수익 분배, 공동 불법행위 또는 기타 연대책임 관계를 형성하지 않습니다.

확인 당사자는 프로젝트 명칭, 표장, 문서, 스크린샷, 커뮤니티 콘텐츠 또는 오픈 소스 저장소 정보를 사용하여 자신의 제3자 인스턴스, 상업 서비스, 유료 요금제 또는 운영에 오픈 소스 프로젝트, 저작권자, 기여자, 유지관리자 또는 커뮤니티가 참여하거나 이를 허가, 승인, 보증 또는 지지한다고 표시하거나 암시해서는 안 됩니다.

확인 당사자는 자신의 배포, 구성, 운영, 홍보, 과금, 사용자 행동 관리, 콘텐츠 처리, 데이터 처리, 계정 이용, API 호출 또는 법률, 규정, 규제 요건, 계약상 의무나 상위 서비스 규칙의 위반으로 발생하는 결과에 대해 독립적으로 책임을 집니다.

합의로 배제하거나 제한할 수 없는 강행법규상 책임은 적용 법률에 따라 처리됩니다. 이러한 법정 예외는 제3자의 배포, 운영 또는 상업 활동에 대한 참여, 권한 부여, 승인, 보증 또는 지지를 의미하지 않습니다.

## 4. 준법 서약 사항

콘솔 기능을 계속 사용함으로써 확인 당사자는 다음 사항을 서약합니다.

1. OpenAI, Anthropic, Google 및 기타 상위 서비스 제공자의 이용약관, 허용 사용 정책, 지원 국가 및 지역, 계정/API 키 규칙, 상업적 이용 요건, 재판매 제한, 위험 통제 요건 및 기술적 제한을 독립적으로 검토했으며 앞으로도 지속적으로 준수합니다.
2. 상위 서비스의 지역 제한, 접근 제한, 계정 제한, 위험 통제, 과금 제한, 신원 확인, 이용 한도 또는 이용약관을 우회하거나 다른 사람의 우회를 돕기 위해 이 프로젝트를 사용하지 않습니다.
3. 필요한 모든 권한, 자격, 신고, 허가, 평가 또는 계약상 합의를 확보하지 않은 상태에서는 일반 대중이나 불특정 사용자 집단에 API 중계, 모델 호출 재판매, 계정 할당량 배분, 구독 공유, 유료 호출, 충전/결제 대행 또는 유사한 서비스를 제공하지 않습니다.
4. 중국 본토 내에서 또는 중국 본토의 대중을 대상으로 생성형 AI 서비스, 딥 합성 서비스, 알고리즘 관련 서비스, API 중계, 유료 호출 또는 기타 규제 대상이 될 수 있는 서비스를 제공하는 경우, 인터넷 정보 서비스, 생성형 AI 서비스, 딥 합성, 알고리즘 신고, 보안 평가, 사이버 보안, 데이터 보안, 개인정보 보호, 콘텐츠 안전, 결제 정산, 세금 및 상위 서비스 권한 부여와 관련하여 적용될 수 있는 모든 의무를 독립적으로 이행합니다.
5. 사업 규모와 위험에 적합한 사용자 관리, 접근 통제, 콘텐츠 검토, 오용 대응, 로그 보관, 개인정보 보호, 데이터 삭제, 민원 처리, 긴급 삭제·중단 및 보안 사고 대응 체계를 유지합니다.
6. 사용자, 고객, 협력사, 유통 채널, 규제 기관 또는 제3자에게 이 문서 제3절에 반하는 진술, 약속, 마케팅 표시 또는 보증을 하지 않습니다.
7. 자신의 배포, 운영, 홍보, 과금, 사용자 행동 관리, 콘텐츠 처리, 데이터 처리, 계정 이용, API 호출 또는 법률, 규정, 규제 요건, 계약상 의무나 상위 서비스 규칙의 위반으로 발생하는 결과에 대해 독립적으로 책임을 집니다.

## 5. 위험 및 책임 고지

Sub2API를 공개 API 서비스, 상업적 중계, 할당량 배분, 팀 공유, 유료 호출 또는 유사한 목적으로 사용하는 경우, 이용약관, 계약 위반, 데이터 보호, 콘텐츠 안전, 소비자 보호, 결제 정산, 세금, 수출 통제, 제재 준수, 사이버 보안, 업종 진입 및 행정 규제와 관련된 위험이 발생할 수 있습니다. 요건은 관할권과 사업 모델에 따라 다르며 시간이 지남에 따라 변경될 수 있습니다.

콘솔의 필수 고지, 문서 링크, 정확한 문구 입력을 통한 확인 및 로컬 확인 기록은 배포와 운영의 위험을 명확하고 눈에 띄며 재현 가능한 방식으로 알리고, 콘솔 사용자가 이 문서의 현재 버전을 읽었음을 확인하며, 오픈 소스 프로젝트, 저작권자, 기여자, 유지관리자와 제3자 배포자, 운영자 또는 통제자 사이의 책임 분리를 명확히 기록하기 위한 것입니다.

## 6. 전자적 확인

콘솔을 계속 사용하고, 문서 링크를 열고, 이 문서를 읽으며, 필요한 확인 문구를 표시된 그대로 정확히 입력함으로써 확인 당사자는 이 문서를 읽고 이해하고 동의했음을 전자적으로 확인합니다. 또한 시스템이 확인한 버전, 확인 시각, 콘솔 계정 식별자, IP 주소 및 User-Agent를 포함하여 필요한 증거를 기록할 수 있음에 동의합니다.
